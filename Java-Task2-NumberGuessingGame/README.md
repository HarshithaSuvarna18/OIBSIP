# Number Guessing Game

## Project Overview
The Number Guessing Game is a console-based application developed using Java. In this game, the computer generates a random number, and the player has to guess the correct number within a limited number of attempts.

The game provides hints such as "Too High!" and "Too Low!" to help the player.

## Technologies Used
- Java 25
- Java Scanner
- Java Random
- Visual Studio Code

## Features
1. Random number generation.
2. User input using Scanner.
3. Too High, Too Low and Correct hints.
4. Attempt counter.
5. Maximum attempt limit.
6. Win and lose messages.
7. Play Again option.
8. Multiple rounds.
9. Score tracking.
10. Round-wise summary.
11. Three difficulty levels:
   - Easy: Numbers 1–50, 10 attempts.
   - Medium: Numbers 1–100, 7 attempts.
   - Hard: Numbers 1–200, 5 attempts.
12. Input validation for invalid choices and guesses.

## How to Run the Project

### Requirements
- Java Development Kit (JDK)
- Visual Studio Code or any Java-compatible editor

### Steps
1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java file:
   `javac NumberGuessingGame.java`

5. Run the application:
   `java NumberGuessingGame`

6. Select a difficulty level and start playing.

## How to Play
1. Select Easy, Medium or Hard.
2. Enter a number within the displayed range.
3. Follow the hints displayed by the game.
4. Guess the correct number before running out of attempts.
5. Choose whether to play another round.
6. View your final score and game summary.
